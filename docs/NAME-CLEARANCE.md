# VERQIVIA — Name / Trademark Clearance Gate

## Status

**Clearance status: NOT COMPLETED.**

The repository may use VERQIVIA as the current working/commercial product name, but no statement in this project should describe VERQIVIA as a registered trademark unless an appropriate clearance and filing process has been completed.

## Required search scope

A professional clearance should evaluate:

- exact `VERQIVIA` word mark;
- phonetically and visually similar marks;
- spelling variants and plural/phonetic variants;
- relevant goods/services classes for software, SaaS, identity/verification, cybersecurity, business services and related integrations;
- national, regional and international records in the jurisdictions where the product will actually be offered.

## Official search resources

- WIPO Global Brand Database: https://www.wipo.int/en/web/global-brand-database
- USPTO Trademark Search: https://www.uspto.gov/trademarks/search
- EUIPO search / eSearch plus / TMview: https://www.euipo.europa.eu/en/search-ip
- UK IPO trade mark search: https://www.gov.uk/search-for-trademark

WIPO notes that its Global Brand Database covers many international and national/regional collections, and also recommends checking national/regional registers and consulting a trademark attorney when appropriate.

## Preliminary public-source observation

A general web search performed during the current repository review did not return an obvious exact `VERQIVIA` trademark/software/company result in the searched sources.

**This is not a trademark clearance, availability opinion, or legal conclusion.** Search-engine results cannot substitute for official register searching, similarity analysis or professional legal review.

## Filing strategy gate

Before material commercial expansion:

1. identify the operating legal entity and intended owner of the mark;
2. define the actual goods/services and relevant Nice classes;
3. run exact and similarity searches in the target jurisdictions;
4. review conflicts with counsel or a qualified trademark professional;
5. decide national/regional filings and, where appropriate, an international filing strategy;
6. only then update public legal/brand language to reflect the verified status.

## Project rule

Until this gate is completed, the project must use language such as:

> Current product name: VERQIVIA

and must not use:

> VERQIVIA is a registered trademark

unless that statement is supported by current official registration records.
